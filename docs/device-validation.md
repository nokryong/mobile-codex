## 0.1.1 모바일 UI 회귀 확인

- [ ] 기존 0.1.0 위에 업데이트 설치, 로그인·대화·선택한 폴더 유지
- [ ] 세로/가로에서 상태 표시줄·카메라 영역·제스처 바·3버튼 탐색 영역과 화면이 겹치지 않음
- [ ] 삼성 키보드/Gboard 열기·닫기 반복: 입력창과 전송 버튼이 키보드 위에 표시되고 빈 여백이 남지 않음
- [ ] 입력 중 회전/분할 화면: 포커스·초안 유지, 긴 요청은 입력창 내부에서 스크롤
- [ ] 과거 답변을 읽는 동안 새 토큰이 와도 스크롤 유지, 최신 메시지 버튼으로 복귀
- [ ] 좁은 320dp 화면, 시스템 글꼴 확대, 다크 모드에서 모델/추론/권한 설정과 파일 메뉴 사용
- [ ] 뒤로 가기: 키보드 → 가장 위의 창 → 파일 패널/사이드바 → 앱 나가기
- [ ] 이미지 1장/2장/4장/여러 장 생성, 순차 도착·부분 실패·생성 중 취소·한도 오류 표시
- [ ] 갤러리 썸네일·스와이프·좌우 버튼, 확대 상태에서 이동, 각 이미지 원본 저장
- [ ] 앱 종료·대화 재개 후 이미지 유지, 0.1.0에서 누락된 이미지 기록 복원
- [ ] PNG/JPEG/WebP와 한글/공백 경로, SAF 문서 제공자 이미지, 존재하지 않는 이미지 오류

호스트의 Robolectric 검사는 API 29/35에서 네이티브 컨테이너 크기를 검증합니다. DOM 검사는 이미지·입력·메뉴 동작을 검증하며, 실제 WebView 렌더링이나 삼성 키보드 동작을 대신하지 않습니다.
