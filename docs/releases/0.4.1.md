# 0.4.1

Android `versionCode 76`, ARM64, Android 10+.

- Optional anonymous login reports now show which operation the app reached, from preparing the account home and requesting a device code to checking authorization and applying the account locally.
- Reports can distinguish an explicitly detected busy account operation, missing file, permission denial or timeout. Other causes are recorded as `unknown`. The preview shows the fixed values that will be sent if you choose to submit. Tokens, email addresses, account details, paths, raw errors, logs and conversations are excluded.
- The diagnostic relay accepts the new login reports and both earlier report formats.

## Install

Install **mobile-codex-0.4.1-arm64.apk** over your existing ARM64 installation to keep local data. The release also includes the update manifest, APK checksum, corresponding tool sources and third-party license notices.
