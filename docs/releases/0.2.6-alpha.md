# Mobile Codex 0.2.6-alpha — 비공개 테스트

`versionCode 51`의 테스트 빌드입니다. 비공개 저장소의 PR에서 검증하고 APK를 제공합니다. 공개 배포는 기기 테스트 후 별도로 진행합니다.

설치용 `mobile-codex-private-pr-test-apk` 아티팩트에는 APK만 들어 있습니다. 도구 소스와 라이선스는 별도의 `mobile-codex-private-pr-tool-sources` 아티팩트로 제공하며, 설치할 때 다운로드할 필요는 없습니다.

## 수정 내용

- 파일 편집 중 이름 변경·이동을 해도 저장 전 편집 내용을 유지합니다.
- 프로젝트를 바꾸면 파일 목록과 검색 경로를 새로 불러옵니다. 이전 프로젝트의 늦은 응답과 파일 변경 요청이 새 프로젝트에 적용되지 않도록 확인합니다.
- Codex·Pro 작업 중에는 입력창 밖의 메시지를 읽거나 복사해도 중지 버튼을 유지합니다.
- 파일 변경 비교에서 실제 변경 구간과 줄 번호를 표시합니다. 떨어진 두 수정 사이의 동일한 내용을 변경으로 표시하지 않습니다.
- 완료·실패·사용자 중지를 구분해 작업 상태와 Android 알림에 표시합니다.

## 기기 테스트

1. 기존 앱 위에 테스트 APK를 설치하고 설정의 버전이 `0.2.6-alpha`인지 확인합니다.
2. 텍스트 파일을 열어 저장하지 않은 내용을 입력한 뒤 이름을 바꾸거나 이동합니다. 입력 내용이 유지되고, 저장하면 변경된 위치의 파일에 반영되는지 확인합니다.
3. 프로젝트 A에서 하위 폴더나 검색 결과를 연 뒤 프로젝트 B로 전환합니다. 목록과 경로가 B의 루트로 바뀌는지, 다시 A로 돌아왔을 때 보존된 편집 내용을 확인할 수 있는지 점검합니다.
4. Codex·Pro 작업 도중 답변 복사 버튼으로 포커스를 옮깁니다. 중지 버튼이 계속 보이고 실제 취소 요청이 전달되는지 확인합니다.
5. 한 파일에서 떨어진 두 줄을 수정하고 변경 비교를 엽니다. 두 수정 사이의 동일한 줄이 삭제·추가로 표시되지 않는지 확인합니다.
6. 작업을 직접 중지합니다. 작업 상태와 알림이 완료가 아닌 중지로 표시되는지 확인합니다.

자동 DOM·브라우저 검사에는 모의 Android 연결을 사용합니다. 실제 Android 키보드, 알림, 파일 제공자, 설치·업데이트 동작의 검증은 위 기기 테스트로 확인합니다.

## Test build

This private candidate preserves unsaved file edits through rename/move, resets file context when projects change, keeps task cancellation accessible, displays bounded diff hunks with line numbers, and distinguishes interruption from success. Same-repository private pull requests produce an APK artifact signed with the original installation certificate after the full CI checks. Physical-device validation is separate from mock-bridge browser tests.

The installation artifact contains only the APK. Corresponding tool sources and licenses are available in a separate private artifact and are not needed for installation.
