# 0.3.6

- Adds **Send error report** for Codex startup and engine errors, also available in Advanced settings. Preview the limited diagnostics and explicitly confirm before sending them to a public GitHub issue. No GitHub sign-in is required in the app.
- Reports contain startup stages, relative timings, transport/error counters, app version and coarse Android/device information. Accounts, tokens, conversations, commands, files, private paths, raw output and permanent device identifiers are excluded.
- Supports cancellation, offline failure, retries and duplicate-click protection. The server validates a fixed schema and destination, limits submissions, preserves original reports and returns the actual issue link.
- The cause of the reported initialize timeout remains unconfirmed. This feature provides diagnostic information for investigation; it does not claim to fix that underlying error.

Production reporting was verified with one clearly marked synthetic issue and an idempotent receipt retry. Physical Android device testing, actual device-code sign-in and upgrading an installed app were not performed.
