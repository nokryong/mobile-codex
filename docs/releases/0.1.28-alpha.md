## 이번 업데이트

- Chat은 공식 ChatGPT 웹 화면을 앱 안에서 바로 사용합니다. 웹의 기존 대화·프로젝트·모델 선택·입력창을 그대로 유지합니다.
- Chat과 Codex 사이드바의 로고 옆에 작은 전환 버튼을 추가했습니다. 두 화면을 오가도 Codex 초안과 진행 중 작업을 유지합니다.
- Chat 답변의 아이콘 태그를 사용자 Firebase 이미지로 표시합니다. 앱 내부 캐시와 기존 이미지 대체 로딩을 지원합니다.
- Codex 사이드바는 제목 줄 아래 전체가 스크롤되며, 프로젝트·일반 대화 항목을 오른쪽 버튼으로 접을 수 있습니다.
- Codex 사이드바 아이콘을 두 줄 메뉴 모양으로 바꿔 파일 패널 아이콘과 구분했습니다.
- 시험용 전송·진단 화면을 사용자 동선에서 제거했습니다. 기존 자체 Chat 로컬 기록은 삭제하지 않습니다.
- 시트·모달 바깥을 눌러 닫을 수 있습니다. 저장 전 확인과 승인 동작은 유지합니다.

### 확인 범위

앱 테스트와 Android 빌드는 릴리즈 CI에서 확인합니다. 실제 계정의 ChatGPT 페이지 구조는 웹 업데이트에 따라 달라질 수 있습니다. 로딩·로그인·연결 오류 중에는 Codex 복귀 버튼이 표시됩니다. 웹 구조 변경으로 사이드바 전환 버튼이 보이지 않으면 Android 뒤로 가기를 사용할 수 있습니다. 웹뷰의 음성·카메라 캡처는 이번 검증 범위에 포함되지 않습니다.
