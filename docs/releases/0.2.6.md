# Mobile Codex 0.2.6

## 한국어

- **Pro 자문:** 작성창의 `+ → Pro에게 물어보기`로 현재 Codex 작업에 자문을 추가합니다. Codex가 질문과 필요한 근거를 준비하고, Pro 답변을 받은 뒤 같은 작업을 이어갑니다. 기존 대화에서도 사용할 수 있으며 선택한 Codex 모델과 설정을 유지합니다.
- **Pro 선택 개선:** ChatGPT가 Work 모드이면 Chat 모드로 전환한 뒤 Pro를 선택합니다. 실제 Pro 선택을 확인한 경우에만 질문을 전송하며, 전송이 불확실하면 자동으로 다시 보내지 않습니다.
- **파일 편집과 작업 상태:** 파일 이름 변경·이동 시 미저장 편집을 보존하고, 프로젝트 전환 시 파일 목록과 검색 경로를 갱신합니다. 작업 중 중지 버튼을 유지하며 완료·실패·중지를 구분합니다. 변경 비교는 실제 수정 구간과 줄 번호를 표시합니다.
- **도구와 플로팅 대화:** 플러그인·스킬·MCP를 탭과 검색으로 나누고, 플로팅 대화는 접으면 캐릭터 얼굴만 표시하도록 개선했습니다.

ARM64 / Android 10 이상. 기존 앱 위에 설치해 업데이트할 수 있습니다. Pro 자문에는 로그인된 ChatGPT 세션과 Pro 사용 권한이 필요합니다.

## English

- **Pro consultation:** Choose `+ → Ask Pro` to add a consultation to the current Codex task. Codex prepares a focused question and supporting context, receives the Pro reply, and continues the same task. Existing chats are supported, and your Codex model and settings are preserved.
- **Pro selection:** Switch ChatGPT from Work to Chat when needed and verify Pro before sending. Uncertain sends are never retried automatically.
- **File editing and task state:** Preserve unsaved edits through rename/move, refresh file context when switching projects, keep cancellation available, distinguish completion from failure and interruption, and show bounded diff hunks with line numbers.
- **Tools and floating chat:** Search separate plugin, skill and MCP tabs. Collapsed floating chat shows the character face.

ARM64 / Android 10 or later. Install over the existing app to update. Pro consultation requires a signed-in ChatGPT session with Pro access.
