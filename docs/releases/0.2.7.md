# Mobile Codex 0.2.7

`versionCode 57`. 0.2.6 이후 private alpha에서 정리한 기능을 public stable 릴리즈로 반영합니다.

## 주요 변경

- **Chat / Codex 전환**을 현재 UI에 정식 반영했습니다. Codex 작업 화면을 유지한 채 공식 ChatGPT 웹 화면으로 전환할 수 있습니다.
- **Pro에게 물어보기**는 다음 Codex 요청에 한 번의 명시적 자문을 붙이는 방식으로 정리했습니다. 실제 Pro 선택 상태를 확인하고, 답변은 같은 Codex 작업의 도구 결과로 돌아옵니다.
- 지원되는 Codex 모델의 **Fast 모드**를 선택적으로 사용할 수 있습니다.
- 파일 승인·프로젝트 전환·취소·알림·diff 표시 등 private alpha에서 다듬은 UI/상태 처리와 회귀 검사를 포함합니다.
- Android의 실험적 **GitHub 프로젝트 직접 동기화는 제거**했습니다. Android는 프로젝트 ID·이름·병합 이력을 JSON 내보내기/가져오기로 교환합니다.
- PC companion의 private GitHub 메타데이터 동기화는 유지됩니다. 소스 파일·대화·인증정보는 이 메타데이터 동기화 범위에 포함되지 않습니다.
- 실험적 **Codex Cloud 작업 화면은 제거**했습니다. 현재 번들 CLI로는 기존 cloud 작업을 이어서 요청할 수 없어 완전한 연속 작업 기능으로 제공하지 않습니다.
- README 영문/한글을 0.2.7의 실제 기능과 제한에 맞게 전면 갱신했습니다.

## 배포

- ARM64 / Android 10+
- applicationId: `dev.mobilecodex.app`
- Codex runtime: `0.155.1`
- APK: `mobile-codex-0.2.7-arm64.apk`

GitHub Actions의 main 빌드가 검사·서명·APK 검증을 통과한 경우에만 릴리즈가 게시됩니다.
