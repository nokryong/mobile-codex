# Mobile Codex 0.2.5

## 한국어

**0.2.5 정식 릴리스**는 기기 간 프로젝트 동기화, GitHub 연결, Pro·Fast 사용, 대화별 독립 관리를 한데 정리한 버전입니다.

### 기기 간 프로젝트 동기화

- Android 휴대폰·태블릿 사이에서, 또는 Android와 PC 보조 도구 사이에서 같은 프로젝트 정보를 공유할 수 있습니다.
- 개인 GitHub 비공개 저장소를 연결하고 업로드할 프로젝트를 선택한 뒤, 동기화 미리보기에서 가져올 정보와 이름 충돌을 확인하고 적용합니다.
- 프로젝트 ID·이름·명시적 병합 이력을 동기화합니다. 각 기기의 작업 폴더는 해당 기기에서 따로 연결하므로 서로 다른 폴더 경로를 사용할 수 있습니다.
- GitHub 대신 JSON 파일로 내보내고 가져오는 방법도 지원합니다. PC에서는 Node.js 20 이상과 저장소에 포함된 CLI 보조 도구를 사용합니다.

현재 동기화는 사용자가 실행하는 **프로젝트 정보 동기화**입니다. 대화 기록·진행 중인 작업·소스 파일·로그인 정보는 전송하지 않으며, 자동 백그라운드 동기화나 공식 Codex Desktop의 대화 이어하기 기능은 포함하지 않습니다.

### GitHub 연결 개선

- 앱에서 로그인 코드를 받고 브라우저에서 승인해 연결할 수 있습니다. 일반 사용자가 OAuth 앱을 만들거나 Client ID를 입력할 필요는 없습니다.
- 로그인·저장소 선택·동기화 요청이 Android 기능으로 올바르게 전달되도록 수정했습니다.
- 연결 실패 시 간결한 안내를 표시하고, 브라우저를 열지 못한 경우 다시 시도할 수 있습니다.

### 다른 대화가 실행 중이어도 개별 관리

한 대화에서 작업하는 동안 관련 없는 대화와 프로젝트를 삭제하거나 이름을 바꿀 수 있습니다. 실행 중인 대화와 해당 프로젝트의 삭제만 보호하며, 다른 항목을 정리해도 진행 중인 작업의 연결을 유지합니다. 프로젝트 제거는 목록의 연결을 해제하는 동작으로, 실제 작업 폴더와 파일은 남습니다.

### Pro·Fast 지원

- **GPT-6-Pro:** 로그인된 ChatGPT 웹 세션을 통해 읽기 전용으로 질문하고 검토할 수 있습니다. 로컬 대화마다 연결된 원격 대화를 유지합니다. 이 경로는 Codex의 파일 수정·셸·휴대폰 제어 도구를 실행하지 않습니다.
- **Fast:** 지원하는 Codex 모델에서 선택적으로 켤 수 있습니다. 기본값은 꺼짐이며, 켜면 사용량이 더 높을 수 있습니다.

기기 간 동기화는 **설정 → 동기화 → GitHub 로그인**에서 시작하세요. [동기화 사용 안내](https://github.com/nokryong/mobile-codex/blob/v0.2.5/docs/project-transfer.ko.md)에서 Android와 PC의 연결 방법을 확인할 수 있습니다.

## English

**Stable release 0.2.5** brings together cross-device project sync, GitHub connectivity, Pro and Fast, and independent chat management.

### Cross-device project sync

- Share project identities, names, and explicit merge history between Android phones/tablets, or between Android and the PC companion CLI.
- Connect your private GitHub repository, choose projects to upload, preview incoming information and name conflicts, then apply the sync. Bind each project's working folder separately on each device.
- JSON file export/import is also supported. The PC companion included in this repository requires Node.js 20 or later.

Sync is **manual and limited to project information**. It does not transfer chat history, running tasks, source files, or credentials. Background sync and conversation continuation in the official Codex Desktop app are not included.

### GitHub connection fixes

Approve the app's login code in your browser without creating an OAuth app or entering a Client ID. Login, repository selection, and sync requests now reach the Android implementation correctly. Failures show concise messages, and opening the browser can be retried.

### Independent chat and project management

Delete or rename unrelated chats and projects while another chat is running. Deletion of the active chat and its project remains protected, and removing other entries preserves the running connection. Removing a project leaves its working folder and files intact.

### Pro and Fast

- **GPT-6-Pro:** Ask questions and review content through your signed-in ChatGPT web session, with a remote conversation retained for each local chat. This read-only route does not run Codex file-write, shell, or phone-control tools.
- **Fast:** Opt in on supported Codex models. It is off by default and can consume more usage.

Start from **Settings → Sync → GitHub sign-in**. See the [sync guide (Korean)](https://github.com/nokryong/mobile-codex/blob/v0.2.5/docs/project-transfer.ko.md) for Android and PC setup.
