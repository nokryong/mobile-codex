# 0.4.2

Android `versionCode 77`, ARM64, Android 10+.

- Updated the light and dark themes across the conversation, sidebar, composer, settings, agent controls, and Live.
- Tapping the compact composer focuses the prompt. The copy button shows a checkmark after copying, and jumping to the latest message respects the reduced-motion setting.
- Swipe right from the left edge to open the sidebar on narrow screens, or swipe left to close it. With a keyboard, use Ctrl/Cmd+B for the sidebar, Ctrl/Cmd+Shift+O for a new conversation, and `/` to focus the prompt outside a text field.
