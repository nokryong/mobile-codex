# Mobile Codex 0.2.0

Android `versionCode` 45. Pro/Fast·대화 개선과 프로젝트 정보 교환 브랜치를 통합한 버전입니다.

## 변경 사항

- 사이드바 상단과 하단의 설정·도구·사용 한도를 고정하고 가운데 프로젝트·대화 목록만 스크롤합니다.
- 헤더와 첫 메시지가 겹치지 않도록 대화 영역을 수정합니다. 오래된 대화는 위로 스크롤할 때 불러오고, 추가 로딩 중 읽던 위치를 유지합니다.
- 프로젝트를 제거하거나 연결 해제하면 해당 대화를 일반 대화로 옮깁니다. 대화 내용·식별자와 실제 폴더·파일은 삭제하지 않습니다. 일시적인 폴더 접근 실패나 아직 연결하지 않은 공유 프로젝트는 제거로 처리하지 않습니다.
- 일반 대화는 프로젝트 선택 없이 기본 `Codex` 폴더를 사용합니다. 기존 앱 내부 작업 경로를 그대로 사용해 기존 파일과 실행 환경을 유지합니다.
- 같은 로컬 대화에서 ChatGPT Pro를 사용하고 원격 프로젝트 `mobile-codex-chat`과 대화 연결을 유지합니다. 진행 상태는 `Pro 답변 중`으로 표시합니다. Pro는 읽기 전용이며 실제 웹 모델 선택을 확인한 뒤 전송합니다.
- 입력창 맨 아래 왼쪽에 Fast 번개 버튼을 추가합니다. 지원 모델에 한해 사용자가 켜며, 기본값은 꺼짐입니다. Fast는 사용량·요금이 더 높을 수 있습니다.
- 시간이 기록된 사용자 메시지에 작은 날짜를 표시합니다. 과거 기록의 날짜를 임의로 만들지 않습니다.
- 프로젝트 ID·이름·명시적 병합 이력을 Android와 PC 보조 도구 사이에서 파일 또는 비공개 GitHub 저장소로 수동 교환합니다. 대화·소스·로컬 경로·인증정보 동기화나 공식 Codex Desktop 연동은 포함하지 않습니다.
- 두 저장소의 `main` 소스 트리와 배포 파일을 맞춥니다. 공개 저장소에서 검증한 APK와 동일한 바이트를 대응 비공개 릴리스에도 게시합니다.

## 호환성과 주의 사항

- ARM64 / Android 10 이상. 기존 설치와 동일한 서명키를 사용합니다. 업데이트를 위해 앱을 삭제할 필요가 없습니다.
- 프로젝트·대화 이전은 기존 기록을 보존하며, 마이그레이션 전 사본을 유지합니다. 프로젝트 연결 해제는 GitHub 연결 해제와 별개입니다.
- 프로젝트 정보 가져오기는 미리보기 후 적용합니다. 병합 이력도 반영하므로 본인이 신뢰하는 파일·비공개 저장소를 사용하세요. 공유 프로젝트 병합의 되돌리기 UI는 아직 없습니다.
- 실제 Android Keystore·문서 제공자·기기 간 GitHub 왕복과 새 APK 설치 후 전체 기능은 자동 테스트와 별도로 확인해야 합니다. ChatGPT 웹 구조 변경은 Pro 경로에 영향을 줄 수 있으며 불확실한 전송은 자동 재전송하지 않습니다.
