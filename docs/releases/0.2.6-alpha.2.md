# Mobile Codex 0.2.6-alpha.2 — 비공개 Pro 자문 테스트

`versionCode 52`의 비공개 테스트 빌드입니다. 비공개 PR에 변경을 올리면 GitHub Actions가 검사, Android 빌드와 기존 설치 인증서 서명을 실행한 뒤 비공개 시험판 릴리스를 게시합니다. 릴리스에서 APK를 받을 수 있습니다. 공개 저장소 배포는 기기 테스트와 사용자 승인 이후 진행합니다.

## Pro 자문 흐름

대화의 주 에이전트는 사용자가 선택한 Codex입니다. `+` 메뉴의 **Pro에게 물어보기**를 선택하면 작성창에 **Pro 자문** 표시가 붙습니다. 메뉴 선택만으로 메시지를 보내지 않으며, 전송 전 표시를 제거할 수 있습니다.

전송하면 Codex가 현재 작업을 파악하고 필요한 근거를 모아 Pro에 보낼 질문을 작성합니다. 앱은 이 질문을 ChatGPT Pro에 한 번 전달합니다. **Pro 검토 답변**을 사용자 대화에 표시하고, 같은 Codex 작업의 도구 결과로 돌려줍니다. Codex는 그 답변을 검토해 이후 작업을 이어갑니다. 별도의 사용자 메시지나 새 Codex 대화가 필요하지 않습니다.

- 모델 선택창에는 실제 Codex 모델만 표시합니다. Pro 자문은 선택한 Codex 모델·추론·서비스 등급·권한 설정을 유지합니다.
- 앱이 Codex 전역 AGENTS, 프로젝트 트리, Git diff나 대화 전체를 Pro 요청에 자동 첨부하지 않습니다. Codex가 작성한 질문과 필요한 근거만 보냅니다.
- Pro 질문에 ChatGPT 측 GitHub 등 연결 도구 사용을 일괄 금지하는 지시를 추가하지 않습니다.
- 명시적으로 요청한 자문마다 Pro 전송은 최대 한 번입니다. 자동 파일 조회 왕복이나 실패 후 자동 재전송은 없습니다.
- 로그인·사용량 제한·시간 초과·취소·전송 불확실성은 실패 상태로 Codex에 반환합니다. 완성된 Pro 답변이 없는 경우 이를 검토 완료로 표시하지 않습니다.
- 기존 대화 기록은 유지합니다. 다른 대화를 열어도 자문 결과는 원래 요청한 대화에 저장합니다.
- Pro 자문은 이전 직접 Pro 대화와 분리된 웹 대화를 사용합니다. 이전에 보낸 AGENTS와 도구 금지 지시가 새 자문에 남지 않도록 첫 자문은 새 웹 대화에서 시작합니다. Codex 스레드와 기존 Pro 메시지 기록은 유지합니다.

기존 0.2.6-alpha의 파일 편집·프로젝트 전환·중지 버튼·변경 비교·중지 알림 수정도 포함합니다.

## 기기 확인

1. 기존 Codex 대화에서 `+`를 눌러 **파일 첨부**, **Pro에게 물어보기** 메뉴가 보이는지 확인합니다. Pro를 선택·제거하는 동안 전송이 발생하지 않는지 확인합니다.
2. Pro 자문을 선택하고 프로젝트 검토를 요청합니다. Codex가 근거를 준비하고 Pro 답변이 표시된 다음 같은 작업을 계속하는지 확인합니다. 원래 모델·추론·권한 설정이 유지되어야 합니다.
3. ChatGPT 웹 대화에서 Codex가 작성한 질문이 한 번만 전달되었는지 확인합니다. 앱이 전역 AGENTS나 프로젝트 전체 목록을 추가하지 않아야 합니다.
4. 자문을 기다리는 중 다른 대화로 이동했다가 돌아옵니다. 결과가 원래 대화에만 표시되어야 합니다. 앱 재생성 이후에도 이미 전송한 질문을 다시 보내지 않아야 합니다.
5. 자문 도중 중지하거나 ChatGPT 로그인·사용량 제한 상황을 확인합니다. 실패 상태가 표시되고 Codex가 무한 대기하거나 Pro를 자동 재호출하지 않아야 합니다.
6. 새 대화와 업데이트 전부터 사용하던 대화에서 모두 같은 흐름을 확인합니다. 기존 Pro 메시지 기록도 계속 볼 수 있어야 합니다.

자동 검사는 도구 요청·결과 연결, 전송 횟수, 요청별 격리, 취소와 작성창 동작을 검증합니다. 실제 로그인된 Android WebView, Pro 사용량 제한과 기기 설치 동작은 위 기기 확인이 필요합니다.
