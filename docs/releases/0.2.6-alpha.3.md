# Mobile Codex 0.2.6-alpha.3 — Pro 선택 수정

`versionCode 53`. ChatGPT 웹의 새 추론 수준 선택기에서 Pro를 고르고 확인하는 과정을 고친 시험판입니다.

## Pro 선택

- 입력창 버튼에 이미 Pro가 표시되면(`6 Pro` 등) 아무것도 누르지 않습니다.
- Pro가 아니면 단계 버튼을 열고 슬라이더를 끝까지 옮긴 뒤 닫습니다. 버전 이름과 관계없이 끝 단계가 Pro입니다.
- 버튼의 화면 글자나 접근성 이름 중 하나가 Pro일 때만 선택된 것으로 봅니다. 전송 버튼을 누르기 직전에도 다시 확인하며, 확인되지 않으면 질문을 보내지 않습니다.
- 확인에 실패하면 오류에 버튼의 실제 글자와 접근성 이름, 메뉴에 보인 항목을 함께 표시합니다.

## 그 밖의 변경

- 기존 대화에서도 Pro 자문을 선택할 수 있습니다. 연결 확인은 전송할 때 다시 하며, 실패하면 이유를 표시합니다.
- 플러그인·스킬·MCP 화면을 탭과 검색으로 나눴습니다. 도구 메뉴의 파일 탐색은 상단바로 일원화했습니다.
- 플로팅 대화는 접으면 캐릭터 얼굴만 표시합니다.
