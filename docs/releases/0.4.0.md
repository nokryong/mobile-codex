# 0.4.0

Android `versionCode 75`, ARM64, Android 10+.

- With the optional in-app Linux environment enabled, text chat can use the official OpenAI Linux ARM64 Codex CLI and check for CLI updates automatically.
- Downloaded packages are checked against their SHA-512 integrity metadata and tested with an isolated app-server initialization before selection. Runtime changes are applied at an idle boundary.
- Both runtimes use the existing GPT account home. Adding or switching accounts does not require a separate Linux login.
- Live voice and installations with Linux disabled continue to use the bundled Android engine. A Linux engine startup failure before initialization falls back to the bundled engine.
- Model-list refresh starts the selected runtime before requesting the current catalog. Available models still depend on the account and upstream service.

Android ARM64 physical-device account switching and actual model responses remain to be verified. Automated checks and APK assembly do not establish physical-device runtime or signed-upgrade behavior.

## Install
Download **mobile-codex-0.4.0-arm64.apk** below and install it on an ARM64 device running Android 10 or later. The release workflow uses the existing signing key and verifies its pinned certificate. Do not uninstall the app if you want to preserve its local data.

This is an independent client, not an official OpenAI app. The release includes the update manifest, SHA-256 checksum, corresponding tool sources and third-party license notices.
