# Mobile Codex 0.2.6-alpha.6 — Codex 클라우드 제거

`versionCode 56`. alpha.5에 넣었던 Codex 클라우드 기능을 다시 뺀 시험판입니다.

- 앱에 들어 있는 Codex CLI(0.155.1)의 `codex cloud`는 새 작업 보내기·목록·diff·적용만 할 수 있고, 기존 작업에 이어서 요청할 수 없습니다. 이어서 하려면 결국 웹으로 가야 하므로, 앱은 Chat 모드(공식 ChatGPT 화면)에서 chatgpt.com/codex를 여는 것으로 충분합니다.
- 사이드바의 **클라우드** 구역과 클라우드 작업 화면을 제거했습니다.
- GitHub 프로젝트 동기화는 alpha.5에서 제거된 그대로입니다. 프로젝트 정보는 파일 내보내기·가져오기로 옮깁니다.
