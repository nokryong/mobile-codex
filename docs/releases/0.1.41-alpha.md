## 이번 업데이트

- **설정 → 도구 → Linux 환경**에서 필요할 때 Linux 개발 환경을 설치할 수 있습니다. 약 152 MB를 별도로 내려받으며, Linux 파일 전체를 APK에 포함하지 않습니다.
- Linux 환경을 켜면 Codex 작업과 앱 터미널에서 Linux 명령을 사용할 수 있습니다. 기존 프로젝트 파일을 같은 위치에서 이어서 작업하고, 필요한 개발 도구는 Linux 안에 설치할 수 있습니다.
- 설치 진행률, 취소·재시도, 사용 전환과 삭제 기능을 추가했습니다. Linux 환경을 삭제해도 연결된 프로젝트 폴더는 유지됩니다.
