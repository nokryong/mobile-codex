# Mobile Codex 0.3.2

## English

- **Conversation icons:** The assistant can choose when to use a character icon based on the conversation.
- **Icon display:** Turning off conversation icons hides both icons and their tags, including in earlier messages.

## 한국어

- **대화 아이콘:** 대화 상황에 맞춰 모델이 필요한 아이콘을 직접 선택합니다.
- **아이콘 표시:** 대화 아이콘을 끄면 이전 답변을 포함해 아이콘과 태그가 함께 숨겨집니다.
