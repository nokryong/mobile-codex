# 0.3.7

Android `versionCode 72`, ARM64, Android 10+.

- Adds separate Codex, Claude and Gemini home-screen usage widgets with compact, wide and tall layouts, light/dark themes, remaining-quota gauges and reset times.
- Shows the lowest remaining valid quota first. Tap the widget to open that provider's account settings, or use its refresh button to check only that provider. Android controls the timing of the requested 30-minute updates; very small widgets hide the refresh button.
- Codex widgets follow the selected ChatGPT account and clear the previous account's quota when switching accounts or signing out. Failed quota checks retain the original observation time instead of making cached values look new.
- The widget redesign adds segmented gauges, provider badges and limit labels, improves rendering on high-density displays, and handles explicit null Codex limit names. See [usage widgets](../usage-widgets.md).
- When the app opens during a widget quota refresh, it takes over the same Codex process with the normal foreground service and model list. Widget-only refreshes release their own process and preserve an existing foreground runtime.

The contributor reported home-screen display and actual account quotas on an SM-S936N running Android 16 in the light theme, using a separate test package. That test did not establish upgrade compatibility with the existing installation. Resize behavior, manual refresh, dark theme and the official signed upgrade still need physical-device verification. Lock-screen availability depends on the widget host; adding these widgets to the lock screen was unavailable on that test device. No additional physical-device testing was performed for this release preparation.
