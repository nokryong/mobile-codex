# 0.4.3

Android `versionCode 78`, ARM64, Android 10+.

- If the active login file disappears while the app is open, adding an account can recover the saved copy for that same profile and continue to the device code. Cancelling keeps the original account and its saved copy.
- An account marked for re-login still uses a separate login home when its saved copy is available. Recovery requires a missing live file and the active profile's own regular backup file.
