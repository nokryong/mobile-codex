## 이번 업데이트

- 사이드바 Chat / Codex 전환과 독립적인 일반 Chat 입력·답변 표시를 추가했습니다.
- 일반 Chat의 모델·추론 슬라이더를 연결하고 Pro 전환 시 설정 버튼을 찾지 못하던 문제를 수정했습니다.
- Chat 기본 모델을 Instant로 설정하고, 전송 전에 실제 웹 설정을 확인합니다.
- 추론 선택 후 시트가 즉시 닫히며, 시트와 모달 바깥을 눌러 닫을 수 있습니다. 저장 전 편집 확인과 승인 요청 대기 상태는 유지합니다.
- ChatGPT 로그인 화면에서 테스트 입력창·진단 로그·재조회 버튼을 제거하고, 앱으로 돌아오는 버튼과 페이지 오류 재시도를 제공했습니다.
- 긴 일반 Chat 사용자 메시지는 접기·펼치기를 지원합니다.

일반 Chat은 공식 ChatGPT 웹 세션으로 로그인합니다. 전체 웹 대화 목록 동기화와 Chat 첨부는 아직 지원하지 않습니다.

## Changes

Adds the Chat / Codex switch, ordinary Chat in the app composer, reasoning selection including the Pro selector fix, automatic model-sheet dismissal, outside-tap dismissal, a dedicated official sign-in screen, and folding for long Chat user messages.
