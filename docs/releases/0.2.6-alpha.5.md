# Mobile Codex 0.2.6-alpha.5 — Codex 클라우드

`versionCode 55`. GitHub 프로젝트 동기화를 빼고 Codex 클라우드 작업을 붙인 시험판입니다.

- 사이드바에 **클라우드** 구역이 생겼습니다. Codex 클라우드 환경별로 작업 수와 진행 중 표시가 보이고, 누르면 그 환경의 작업 목록이 열립니다. 로컬 프로젝트와 섞이지 않습니다.
- 작업 목록에서 상태(진행 중·완료·적용됨·오류)와 추가/삭제 줄 수를 봅니다. 폰과 태블릿에서 같은 계정의 같은 목록이 보입니다.
- 작업을 누르면 변경 diff를 보고, 브라우저에서 열거나 **로컬 프로젝트에 적용**할 수 있습니다. 적용은 확인을 받은 뒤, 지금 열린 Git 저장소 프로젝트에만 합니다. 충돌하면 적용하지 않습니다.
- `+` 또는 **새 작업**으로 환경, 요청, 브랜치, 시도 횟수(1~4)를 정해 클라우드 작업을 보냅니다.
- 앱에 들어 있는 Codex 0.155.1의 `codex cloud` 명령을 쓰며, 앱에 로그인한 ChatGPT 계정을 그대로 씁니다. 환경은 chatgpt.com/codex에서 먼저 만들어야 합니다.
- 설정의 **동기화** 탭과 GitHub 로그인을 제거했습니다. 프로젝트 파일 내보내기·가져오기는 그대로입니다.
