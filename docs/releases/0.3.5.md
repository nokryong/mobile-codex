# 0.3.5

- Adding or reconnecting a Codex account starts device login without trying to restore the open conversation in the temporary login HOME. Cancellation and failed login restore the previous HOME and account; saved conversation history and remote IDs are retained.
- A conversation restore error after successful authentication is reported separately and does not invalidate the completed login.
- Claude Code and Antigravity status checks distinguish an explicit sign-out from a timeout or network failure. Unanswered checks preserve the last confirmed connection, model list and usage; first-time unanswered checks show Status unavailable.
- Provider checks run sequentially, reuse successful results for five minutes, and avoid competing with active turns.

Physical Android device testing was not performed for this release. Automated protocol tests use simulated account and CLI responses; actual device-code authentication and upgrading an installed app still require device verification.
