# Mobile Codex 0.2.6-alpha.4 — Chat 모드 전환

`versionCode 54`. ChatGPT가 Work 모드일 때 Pro를 선택하지 못하던 문제를 고친 시험판입니다.

- Work 모드에서는 추론 수준에 `Extra High` 같은 작업용 단계만 보이고 Pro가 없습니다. Pro를 고르기 전에 상단 Chat/Work 전환에서 Chat을 누르고, 화면이 바뀐 뒤 진행합니다.
- 이미 Chat 모드이거나 전환 버튼이 없는 화면은 그대로 둡니다.
- 전환에 실패하면 "ChatGPT를 Work 모드에서 Chat 모드로 바꾸지 못했습니다"로 멈추며 질문을 보내지 않습니다.
