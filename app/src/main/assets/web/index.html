답변 언어, 말투, 작업 방식 등 모든 대화에 적용할 기본 지침을 작성하세요. 프로젝트의 AGENTS.md와 함께 사용됩니다.

휴대폰 제어

접근성 연결 상태를 확인하는 중입니다.

요청한 작업을 위해 다른 앱의 화면을 읽고 탭·입력·스크롤합니다. 화면 내용과 이미지는 AI 서비스로 전송되며 Codex 기록에 남을 수 있습니다.
